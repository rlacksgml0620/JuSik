# 📈 주식 게임 (JuSik)

웹에서 **모든 참가자가 같은 차트를 공유**하며 실제 주식처럼 사고파는 실시간 멀티플레이 모의투자 게임입니다.

가격은 서버 하나가 관리합니다. 플레이어의 주문은 실제 호가창에서 매칭되기 때문에 **내가 대량으로 사면 모두의 차트에서 가격이 오릅니다.**

## 실행

```bash
npm install
npm start            # http://localhost:3000
```

여러 브라우저나 기기에서 같은 주소로 접속하면 같은 시장에서 함께 거래합니다.

| 환경변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `3000` | 서버 포트 |
| `DATA_DIR` | `./data` | 게임 상태 저장 위치 (15초마다, 종료 시 저장) |

## 게임 규칙

- 시작 자금 **10,000,000원**. 계좌 초기화로 언제든 다시 시작할 수 있습니다.
- 종목 4개 (모두 가상의 회사): 구름전자, 바나나모빌리티, 도깨비바이오, 달빛엔터
- **지정가 / 시장가** 주문, 미체결 주문 취소
- 가격-시간 우선 원칙으로 매칭하며, 국내 증시와 같은 호가 단위를 씁니다.
- 수수료 0.015% (매수·매도), 매도 시 거래세 0.18%
- 가격제한폭: 기준가(전일 종가, 한국시간 자정 기준) ±30%
- 공매도와 미수는 없습니다 (가진 현금과 주식 안에서만 거래).
- 1~2분마다 랜덤 **뉴스**가 터져 종목 가격이 출렁입니다.
- 실시간 **랭킹**(총자산 기준), **채팅**

## 구조

```
server.js          HTTP(정적 파일) + WebSocket 서버, 브로드캐스트 루프, 저장
src/market.js      시장 엔진: 호가창/매칭, 계좌 정산, 봇, 뉴스, 캔들
public/            클라이언트 (lightweight-charts 캔들 차트)
test/              엔진 불변식 테스트 (npm test)
```

- **시장조성 봇**은 매초 내재가치 주변에 호가를 깔아 유동성을 공급합니다. **노이즈 봇**은 소량의 시장가 주문으로 거래를 일으킵니다.
- 체결가는 내재가치를 끌어당깁니다. 그래서 호가를 쓸어 담는 대량 주문은 가격을 실제로 움직입니다.
- 서버는 0.5초마다 시세·호가·체결을, 2초마다 랭킹을 모든 클라이언트에 보냅니다.
- 계정은 닉네임과 브라우저에 저장된 토큰으로 식별합니다 (비밀번호 없음).

## 배포

WebSocket을 지원하는 Node 호스팅이면 어디서든 돌아갑니다 (Render, Railway, Fly.io, VPS 등).
상태가 파일로 저장되므로, 재시작 후에도 유지하려면 `DATA_DIR`에 영구 디스크를 연결하세요.

```bash
docker build -t jusik .
docker run -p 3000:3000 -v jusik-data:/data jusik
```
