# 📈 주식 로그라이크 (JuSik)

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/rlacksgml0620/JuSik)

방에 모여 **같은 차트**로 주식을 사고팔고, 라운드마다 **카드**를 골라 빌드를 만들고, **기업 미니게임**으로 주식을 따내는 멀티플레이 로그라이크 게임입니다. 마지막 라운드가 끝났을 때 총자산 1위가 승리합니다.

## 실행

```bash
npm install
npm start            # http://localhost:3000
```

방을 만든 뒤 방 코드나 링크(`http://주소/#ABCD`)를 친구에게 보내면 됩니다.

## 게임 흐름

```
대기실 → [거래 라운드 → 카드 선택] → [거래 → 카드] → [거래 → 미니게임] → … → 최종 순위
```

- **카운트다운**: 게임 시작 전 5초, 매 라운드 개장 전 3초 카운트다운이 있습니다 (호가창은 미리 볼 수 있음).
- **거래 라운드 (= 하루)**: 모두가 같은 호가창에서 지정가·시장가로 거래합니다. 큰 주문은 모두의 차트를 움직입니다.
  - 라운드가 끝나면 미체결 주문은 취소됩니다.
  - 다음 라운드의 기준가는 직전 종가이고, 가격제한폭은 ±30%입니다.
- **카드 선택**: 매 라운드 뒤 3장 중 1장을 고릅니다 (20초, 시간이 지나면 자동 선택).
- **미니게임**: 3·6·9… 라운드 뒤에는 카드 대신 기업 미니게임이 열립니다. 순위와 점수에 따라 그 회사 주식을 받습니다.
- 방장이 라운드 수(6/8/10, 기본 8)와 라운드 시간(45/60/90초, 기본 60초)을 정합니다. 최대 4명입니다.

### 시장과 이벤트

- **우상향**: 시장지수(시작 1000)는 라운드마다 평균 약 +3%씩 오르는 추세선을 따라갑니다. 이벤트로 크게 흔들려도 결국 추세로 돌아옵니다. 200판 시뮬레이션에서 8라운드 뒤 지수는 하위 10% 판에서도 +17%, 중간값은 +34%였습니다.
- **이벤트** (25~45초마다)

  | 이벤트 | 효과 |
  |---|---|
  | 개별 호재/악재 | 한 종목 ±5~14% |
  | 급등/폭락 | 한 종목 ±18~27% |
  | 🚀 전체 호황 | 모든 종목 +6~13% |
  | 🥶 전체 불황 | 모든 종목 -5~11% |
  | 🔥 테마 | 두 종목 +8~16% |
  | 🚨 감사의견 거절 | 한 종목 -15~25%, 관리종목 지정 |
  | 🛟 회생 기대 | 관리종목 +12~20%, 상장 유지 확률 상승 |

- **상장폐지**
  - 관리종목은 라운드가 끝날 때 심사합니다. 주가가 추세 대비 반토막 미만이면 무조건 상장폐지되고, 아니면 50% 확률입니다 (회생 뉴스가 있었으면 25%).
  - 주가가 추세 대비 절반 아래로 떨어지면 관리종목으로 지정되고, 다음 라운드가 끝날 때 심사합니다.
  - 상장폐지된 종목의 보유 주식은 0원이 됩니다.
  - 다음 라운드에 그 자리로 새 회사가 **신규 상장**합니다. 신규 상장 종목은 첫 라운드 변동성이 2배입니다.
  - 200판 시뮬레이션에서 상장폐지는 대략 두 판에 한 번꼴이었습니다.

### 카드 (등급: 일반 · 희귀 · 영웅 · 전설, 등급이 높을수록 수치가 큼)

| 카드 | 종류 | 효과 |
|---|---|---|
| 📈 레버리지 | 영구 | 모든 손익 배율 +0.5 ~ +2.5 (손실도 커짐!) |
| ⚡ 단타의 신 | 지속 | 30~90초 동안 손실 매도 시 50~90% 확률로 손실 무효화, 수익 +20~100% |
| 🛡️ 손절 방패 | 영구 | 손실 15~60% 감소 |
| 💳 VIP 계좌 | 영구 | 수수료·거래세 면제 (희귀 이상) |
| 💰 긴급 자금 | 즉시 | 현금 50만 ~ 700만 원 |
| 🏦 복리 예금 | 영구 | 라운드마다 현금 이자 1 ~ 6% |
| 🌾 배당 투자 | 영구 | 라운드마다 보유주식 평가액의 1.5 ~ 8% |
| 🕵️ 내부자 정보 | 횟수 | 다음 뉴스 1~5건을 15초 먼저 받음 |
| 🚀 작전 세력 | 즉시 | 다음 라운드에 특정 종목 +5 ~ 20% (모두에게 영향) |
| 💣 악성 루머 | 즉시 | 다음 라운드에 특정 종목 -5 ~ 20% |
| 🎁 스톡옵션 | 즉시 | 특정 종목 주식 80만 ~ 1,000만 원어치 |
| 🍀 행운의 부적 | 영구 | 높은 등급 카드 확률 증가 |
| 🔄 다시 뽑기권 | 횟수 | 카드 선택지 새로 뽑기 1~5회 |
| 🎮 미니게임 고수 | 영구 | 미니게임 보상 +25 ~ 120% (최대 x2.5). 남은 미니게임이 있을 때만 등장 |
| 🎲 도박꾼 | 즉시 | 50%로 현금 +40~100%, 50%로 -20~25% (희귀 이상) |
| 🐻 인버스 베팅 | 1라운드 | 다음 라운드 시장지수 1% 하락마다 현금 10만 ~ 60만 원 (올라도 손해 없음) |
| 🐂 불장 베팅 | 1라운드 | 다음 라운드 시장지수 1% 상승마다 현금 8만 ~ 50만 원 |
| 🧯 상장폐지 보험 | 영구 | 보유 종목이 상장폐지되면 매입금액의 50 ~ 120% 보상 |
| 🏧 마진 대출 | 즉시 | 현금 300만 ~ 1,500만 원을 빌림. 110%를 총자산에서 차감 |
| 🔭 차트 분석가 | 라운드 | 1~5라운드 동안 모든 종목의 적정가(주가가 끌려가는 값)를 차트에 표시 |
| 🏹 로빈후드 | 즉시 | 나를 뺀 1위의 주문가능 현금 4 ~ 15%를 빼앗음 (2인 이상) |

### 미니게임 (20초, 모든 플레이어가 같은 배치/문제)

| 기업 | 게임 |
|---|---|
| 구름전자 | 불량 칩 검수: 빨간 칩 빨리 누르기 |
| 바나나모빌리티 | 정밀 주차: 움직이는 차를 주차 칸에 멈추기 (5회) |
| 도깨비바이오 | 신약 배합 계산: 암산 |
| 달빛엔터 | 무대 큐 사인: 반응속도 (4회) |

보상은 1위 약 150만 원, 2위 100만 원, 3위 60만 원, 4위 30만 원어치 주식입니다. 점수가 기준에 못 미치면 최대 절반까지 줄어듭니다.

## 구조

```
server.js          HTTP + WebSocket, 방 라우팅, 루프
src/market.js      시장 엔진: 호가창 매칭, 계좌 정산, 카드 효과 적용(손익 배율 등), 봇, 뉴스
src/cards.js       카드 정의, 등급 추첨, 적용
src/room.js        방 상태 머신: 로비 → 거래 → 카드/미니게임 → 종료
public/            클라이언트 (app.js, minigames.js, lightweight-charts 차트)
test/              엔진 불변식 테스트 + 방 전체 진행 테스트 (npm test)
```

- 레버리지 등 손익 카드는 **개인 정산에만** 적용됩니다. 시장 가격은 모두에게 같습니다.
- 레버리지 손실로 현금이 바닥나면 0원에서 멈춥니다 (깡통 보호).
- 미니게임 점수는 클라이언트가 계산해 보내고, 서버는 게임별 최대 점수로 상한만 겁니다. 친구끼리 하는 게임을 전제로 합니다.
- 방은 메모리에만 있습니다. 서버를 재시작하면 진행 중인 게임은 사라집니다.
- 새로고침하거나 연결이 끊겨도 같은 브라우저라면 자동으로 다시 들어갑니다.

개발용: `DEV_FAST=1 npm start`로 실행하면 4라운드 × 8초의 짧은 게임으로 흐름을 빠르게 확인할 수 있습니다. 이때 채팅에 `/event boom`(boom·bust·audit·surge·theme·news) 또는 `/delist 종목코드`를 입력하면 이벤트를 바로 일으킬 수 있습니다 (DEV_FAST일 때만 동작).

## 배포

### Render (추천)

1. 맨 위의 **Deploy to Render** 버튼을 누릅니다. 처음이면 GitHub 계정으로 로그인합니다.
2. 설정은 `render.yaml`에서 자동으로 채워집니다. **Apply**만 누르면 됩니다.
3. 배포가 끝나면 `https://jusik-xxxx.onrender.com` 같은 주소가 생깁니다. 그 주소를 친구들에게 공유하면 됩니다.

직접 설정하려면 **New → Web Service**를 고르고 아래처럼 입력합니다.
- Build Command: `npm ci`
- Start Command: `npm start`
- Health Check Path: `/healthz`

무료 플랜에서는 15분 동안 접속이 없으면 서버가 잠듭니다. 잠든 뒤 첫 접속은 깨어나는 데 1분 가까이 걸립니다. 서버가 잠들거나 재배포되면 열려 있던 방도 사라집니다.

### 그 외

WebSocket을 지원하는 Node 호스팅(Railway, Fly.io, VPS 등)이면 됩니다.

```bash
docker build -t jusik .
docker run -p 3000:3000 jusik
```
