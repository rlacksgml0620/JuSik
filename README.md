# 📈 주식 로그라이크 (JuSik)

방에 모여 **같은 차트**로 주식을 사고팔고, 라운드마다 **카드**를 골라 빌드를 만들고, **기업 미니게임**으로 주식을 따내는 멀티플레이 로그라이크 게임입니다. 마지막 라운드가 끝났을 때 총자산 1위가 승리합니다.

## 실행

```bash
npm install
npm start            # http://localhost:3000
```

방을 만든 뒤 방 코드나 링크(`http://주소/#ABCD`)를 친구에게 보내면 됩니다.

## 게임 흐름

```
대기실 → [거래 라운드 → 카드 선택] → [거래 → 카드] → [거래 → 미니게임] → … → 최종 순위
```

- **거래 라운드 (= 하루)**: 모두가 같은 호가창에서 지정가·시장가로 거래합니다. 큰 주문은 모두의 차트를 움직입니다.
  - 라운드가 끝나면 미체결 주문은 취소됩니다.
  - 다음 라운드의 기준가는 직전 종가이고, 가격제한폭은 ±30%입니다.
- **카드 선택**: 매 라운드 뒤 3장 중 1장을 고릅니다 (15초, 시간이 지나면 자동 선택).
- **미니게임**: 3·6·9… 라운드 뒤에는 카드 대신 기업 미니게임이 열립니다. 순위와 점수에 따라 그 회사 주식을 받습니다.
- 방장이 라운드 수(6/10/15)와 라운드 시간(30/45/60초)을 정합니다. 최대 8명입니다.

### 카드 (등급: 일반 · 희귀 · 영웅 · 전설, 등급이 높을수록 수치가 큼)

| 카드 | 종류 | 효과 |
|---|---|---|
| 📈 레버리지 | 영구 | 모든 손익 배율 +0.5 ~ +2.5 (손실도 커짐!) |
| ⚡ 단타의 신 | 지속 | 30~90초 동안 손실 매도 시 50~90% 확률로 손실 무효화, 수익 +20~100% |
| 🛡️ 손절 방패 | 영구 | 손실 15~60% 감소 |
| 💳 VIP 계좌 | 영구 | 수수료·거래세 면제 (희귀 이상) |
| 💰 긴급 자금 | 즉시 | 현금 50만 ~ 700만 원 |
| 🏦 복리 예금 | 영구 | 라운드마다 현금 이자 1 ~ 6% |
| 🌾 배당 투자 | 영구 | 라운드마다 보유주식 평가액의 1.5 ~ 8% |
| 🕵️ 내부자 정보 | 횟수 | 다음 뉴스 1~5건을 15초 먼저 받음 |
| 🚀 작전 세력 | 즉시 | 다음 라운드에 특정 종목 +5 ~ 20% (모두에게 영향) |
| 💣 악성 루머 | 즉시 | 다음 라운드에 특정 종목 -5 ~ 20% |
| 🎁 스톡옵션 | 즉시 | 특정 종목 주식 80만 ~ 1,000만 원어치 |
| 🍀 행운의 부적 | 영구 | 높은 등급 카드 확률 증가 |
| 🔄 다시 뽑기권 | 횟수 | 카드 선택지 새로 뽑기 1~5회 |
| 🎮 미니게임 고수 | 영구 | 미니게임 보상 +30 ~ 200% |
| 🎲 도박꾼 | 즉시 | 50%로 현금 +40~100%, 50%로 -20~25% (희귀 이상) |

### 미니게임 (20초, 모든 플레이어가 같은 배치/문제)

| 기업 | 게임 |
|---|---|
| 구름전자 | 불량 칩 검수: 빨간 칩 빨리 누르기 |
| 바나나모빌리티 | 정밀 주차: 움직이는 차를 주차 칸에 멈추기 (5회) |
| 도깨비바이오 | 신약 배합 계산: 암산 |
| 달빛엔터 | 무대 큐 사인: 반응속도 (4회) |

보상은 1위 약 200만 원, 2위 130만 원, 3위 80만 원, 4위 이하 50만 원어치 주식입니다. 점수가 기준에 못 미치면 최대 절반까지 줄어듭니다.

## 구조

```
server.js          HTTP + WebSocket, 방 라우팅, 루프
src/market.js      시장 엔진: 호가창 매칭, 계좌 정산, 카드 효과 적용(손익 배율 등), 봇, 뉴스
src/cards.js       카드 정의, 등급 추첨, 적용
src/room.js        방 상태 머신: 로비 → 거래 → 카드/미니게임 → 종료
public/            클라이언트 (app.js, minigames.js, lightweight-charts 차트)
test/              엔진 불변식 테스트 + 방 전체 진행 테스트 (npm test)
```

- 레버리지 등 손익 카드는 **개인 정산에만** 적용됩니다. 시장 가격은 모두에게 같습니다.
- 레버리지 손실로 현금이 바닥나면 0원에서 멈춥니다 (깡통 보호).
- 미니게임 점수는 클라이언트가 계산해 보내고, 서버는 게임별 최대 점수로 상한만 겁니다. 친구끼리 하는 게임을 전제로 합니다.
- 방은 메모리에만 있습니다. 서버를 재시작하면 진행 중인 게임은 사라집니다.
- 새로고침하거나 연결이 끊겨도 같은 브라우저라면 자동으로 다시 들어갑니다.

개발용: `DEV_FAST=1 npm start`로 실행하면 4라운드 × 8초의 짧은 게임으로 흐름을 빠르게 확인할 수 있습니다.

## 배포

WebSocket을 지원하는 Node 호스팅(Render, Railway, Fly.io, VPS 등)이면 됩니다.

```bash
docker build -t jusik .
docker run -p 3000:3000 jusik
```
